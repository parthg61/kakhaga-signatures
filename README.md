# Kakhaga Email Signatures

This repository contains ready-to-use HTML email signatures for the Kakhaga team.

## How to use

1. Go to the [signatures directory](./signatures).
2. Click on your name's HTML file.
3. You will see the raw HTML code. 
4. **To install in Gmail/Outlook:**
   - Instead of copying the code, it's easiest to open the HTML file in a web browser. (You can do this by downloading the file and double-clicking it).
   - Once it is open in your browser, select the entire signature (Ctrl+A or Cmd+A) and copy it (Ctrl+C or Cmd+C).
   - Paste it directly into your email client's signature settings box.
